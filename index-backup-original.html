Containers

Gérer les Containers

Toutes les commandes pour créer, démarrer, arrêter et inspecter vos containers.

Lancer un container

La commande docker run crée et démarre un container en une seule étape. Combinez les flags pour configurer finement votre environnement.

  • -d Mode détaché (background)
  • -p Mapping de ports host:container
  • -v Montage de volume
  • -e Variables d'environnement
  • --name Nommer le container
  • --rm Supprimer à l'arrêt
bash 
# Lancer un container simple
docker run hello-world

# Container en mode interactif
docker run -it ubuntu bash

# Serveur web en arrière-plan
docker run -d \
  --name mon-nginx \
  -p 8080:80 \
  -v $(pwd)/html:/usr/share/nginx/html \
  nginx

# Container avec variables d'env
docker run -d \
  --name ma-db \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=secret \
  -e POSTGRES_DB=myapp \
  -p 5432:5432 \
  postgres:15

Gérer le cycle de vie

Démarrez, arrêtez, redémarrez et supprimez vos containers avec les commandes de base.

  • ps Lister les containers actifs
  • stop Arrêt gracieux (SIGTERM)
  • kill Arrêt immédiat (SIGKILL)
  • rm Supprimer un container
  • exec Exécuter dans un container
  • logs Voir les journaux
bash 
# Lister les containers
docker ps          # actifs seulement
docker ps -a       # tous

# Démarrer / arrêter
docker start mon-nginx
docker stop mon-nginx
docker restart mon-nginx

# Entrer dans un container
docker exec -it mon-nginx bash

# Voir les logs en temps réel
docker logs -f mon-nginx

# Supprimer
docker rm mon-nginx
docker rm -f mon-nginx   # forcer si actif

# Nettoyer tous les containers arrêtés
docker container prune

Inspecter & Monitorer

Analysez l'état interne de vos containers, consultez les ressources consommées et copiez des fichiers.

  • inspect Détails JSON complets
  • stats CPU, mémoire, réseau live
  • top Processus du container
  • cp Copier fichiers
  • diff Changements filesystem
bash 
# Inspecter un container (JSON)
docker inspect mon-nginx

# Obtenir l'IP du container
docker inspect -f \
  '{{range.NetworkSettings.Networks}}{{.IPAddress}}{{end}}' \
  mon-nginx

# Statistiques en temps réel
docker stats
docker stats mon-nginx

# Processus actifs
docker top mon-nginx

# Copier un fichier depuis le container
docker cp mon-nginx:/etc/nginx/nginx.conf ./nginx.conf

# Voir les modifications du filesystem
docker diff mon-nginx

Réseau Docker

Créez des réseaux isolés pour faire communiquer vos containers de façon sécurisée.

  • bridge Réseau par défaut isolé
  • host Partage le réseau host
  • overlay Multi-hôtes (Swarm)
  • none Isolation totale
bash 
# Créer un réseau personnalisé
docker network create mon-reseau

# Lister les réseaux
docker network ls

# Connecter un container au réseau
docker run -d \
  --name app \
  --network mon-reseau \
  my-app

docker run -d \
  --name db \
  --network mon-reseau \
  postgres:15

# Les containers se trouvent par nom
# app peut contacter "db" directement

# Inspecter le réseau
docker network inspect mon-reseau

Commandes de build

bash 
# Construire une image
docker build -t mon-app:1.0 .

# Build avec arguments
docker build \
  --build-arg NODE_ENV=production \
  -t mon-app:prod .

docker images

docker rmi mon-app:1.0

docker tag mon-app:1.0 username/mon-app:1.0

Docker Compose

Orchestrer avec Compose

Définissez et lancez des applications multi-containers avec un simple fichier YAML.

Stack complète en un fichier

Docker Compose vous permet de définir toute votre infrastructure applicative dans un fichier docker-compose.yml verscionnable.

⚡
Un seul démarrage

Lancez tous vos services avec docker compose up

🔗
Dépendances gérées

Définissez l'ordre de démarrage avec depends_on

📋
Variables d'env

Utilisez des fichiers .env pour configurer vos services

📦
Volumes partagés

Partagez des données entre services facilement

Commandes essentielles

docker compose up -dDémarrer en arrière-plan
docker compose downArrêter et supprimer
docker compose psÉtat des services
docker compose logs -fLogs en live
docker compose buildReconstruire les images
docker compose scale web=3Scaler un service
docker-compose.yml 
version: '3.9'

services:
  web:
    build: ./frontend
    ports:
      - "3000:3000"
    environment:
      - REACT_APP_API_URL=http://api:8000
    depends_on:
      - api
    networks:
      - app-network

  api:
    build: ./backend
    ports:
      - "8000:8000"
    environment:
      - DATABASE_URL=postgresql://admin:secret@db:5432/myapp
      - REDIS_URL=redis://cache:6379
    depends_on:
      - db
      - cache
    volumes:
      - ./backend:/app
    networks:
      - app-network

  db:
    image: postgres:15-alpine
    volumes:
      - postgres_data:/var/lib/postgresql/data
    environment:
      - POSTGRES_USER=admin
      - POSTGRES_PASSWORD=secret
      - POSTGRES_DB=myapp
    networks:
      - app-network

  cache:
    image: redis:7-alpine
    networks:
      - app-network

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf
    depends_on:
      - web
      - api
    networks:
      - app-network

volumes:
  postgres_data:

networks:
  app-network:
    driver: bridge
